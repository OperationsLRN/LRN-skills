# Checking for Updates

Skills in this repo are versioned and periodically improved. Check for updates
quarterly (or before a major project milestone).

## How to update

```bash
# From inside the LRN-skills folder
git pull origin main
```

## What gets updated

| Folder | Update frequency | Notes |
|--------|-----------------|-------|
| `email-organizer/` | As-needed | CRM-specific — changes with Gmail API updates |
| `google-workspace-skill/` | As-needed | Updates with OAuth or Google API changes |
| `aws-cli-safe/` | Rarely | Stable |
| `aws-account-bootstrap/` | Rarely | Stable |
| `deployer/` | Occasional | Follows deploy.sh changes |
| `core/` | Quarterly | New techniques, model updates |
| `qa/suite/` | Quarterly | New test patterns, security rules |
| `qa/essentials/` | Quarterly | New review patterns |
| `design/` | Quarterly | Figma API changes, new components |
| `efficiency/` | Quarterly | Pricing/model updates, new compression techniques |

## Notifications

No automated notifications. Bookmark this repo and check quarterly:
https://github.com/OperationsLRN/LRN-skills

Significant changes will be noted in each skill folder's `LESSONS.md`.
